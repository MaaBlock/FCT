详细描述

管理渲染管线的状态、资源布局和缓存。

Layout 是 FCT 库的核心类之一，它封装了与特定渲染效果相关的所有配置， 包括顶点布局、资源（纹理、常量缓冲区、采样器）布局、着色器以及其他管线状态。 它通过构造函数链式配置，并提供了一套完整的渲染命令接口。
