顶点着色器详解

概述

顶点着色器（Vertex Shader）是图形渲染管线中的第一个可编程阶段，负责处理输入的顶点数据并将其转换为屏幕空间坐标。每个顶点都会独立地通过顶点着色器进行处理。

工作原理

主要功能

1. 坐标变换

  • **模型变换**：将顶点从模型空间转换到世界空间
  • **视图变换**：将顶点从世界空间转换到相机空间
  • **投影变换**：将顶点从相机空间转换到裁剪空间

2. 属性计算

  • 计算光照所需的法线向量
  • 处理纹理坐标
  • 计算顶点颜色
  • 传递自定义属性给片段着色器

3. 顶点动画

  • 骨骼动画（蒙皮）
  • 顶点变形
  • 程序化动画

输入和输出

输入属性

// 顶点位置
layout(location = 0) in vec3 aPosition;
// 法线向量
layout(location = 1) in vec3 aNormal;
// 纹理坐标
layout(location = 2) in vec2 aTexCoord;
// 顶点颜色
layout(location = 3) in vec4 aColor;

输出属性

// 传递给片段着色器的属性
out vec3 FragPos;
out vec3 Normal;
out vec2 TexCoord;
out vec4 Color;
// 必须输出的内置变量
gl_Position = projectionMatrix * viewMatrix * modelMatrix * vec4(aPosition, 1.0);

常见应用场景

1. 基础渲染

  • 简单的MVP变换
  • 基本的属性传递

2. 光照计算

  • 计算世界空间法线
  • 传递顶点到光源的向量
  • 预计算光照强度

3. 动画系统

  • 骨骼动画的顶点蒙皮
  • 变形目标动画
  • 程序化顶点动画

4. 特效处理

  • 顶点噪声
  • 波浪效果
  • 爆炸效果

性能考虑

优化建议

  • ✅ 尽量在顶点着色器中进行计算，减少片段着色器负担
  • ✅ 使用uniform变量存储不变的数据
  • ✅ 避免在顶点着色器中进行复杂的分支操作
  • ❌ 不要在顶点着色器中进行纹理采样（除非必要）

性能特点

  • 顶点数量直接影响性能
  • 计算复杂度与顶点数成正比
  • 现代GPU对顶点处理优化良好

在FCT中的实现

FCT库中的顶点着色器实现遵循以下设计原则：

1. 模块化设计

class VertexShader {
public:
virtual void setMVPMatrix(const Matrix4& mvp) = 0;
virtual void setAttributes(const VertexAttributes& attrs) = 0;
virtual void execute() = 0;
};

2. 可配置性

  • 支持动态着色器编译
  • 提供预定义的着色器模板
  • 允许自定义着色器代码

3. 平台兼容性

  • 支持OpenGL、Vulkan、DirectX
  • 自动处理API差异
  • 统一的着色器接口
