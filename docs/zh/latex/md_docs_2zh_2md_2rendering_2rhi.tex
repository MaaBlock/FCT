RHI（\+Render Hardware Interface，渲染硬件接口）是一个抽象层，它隐藏了不同图形\+API之间的差异，为上层应用提供统一的渲染接口。

想象一下：
\begin{DoxyItemize}
\item 你想开发一个跨平台的图形应用
\item Windows上有\+Direct\+X，\+Linux/\+Mac上有\+Open\+GL，移动设备上有\+Open\+GL ES，现代平台还有\+Vulkan
\item 每个\+API的调用方式、概念、数据格式都不同
\item RHI就像一个"{}翻译官"{}，让你用同一套代码在所有平台上运行
\end{DoxyItemize}
