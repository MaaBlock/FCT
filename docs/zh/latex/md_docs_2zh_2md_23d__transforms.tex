\begin{DoxyItemize}
\item {\bfseries{定义}}：物体自身的坐标系，以物体中心为原点
\item {\bfseries{特点}}：每个物体都有自己独立的局部坐标系
\item {\bfseries{用途}}：建模时使用，便于物体的创建和编辑
\item {\bfseries{示例}}：一个立方体的顶点坐标可能是 (-\/1,-\/1,-\/1) 到 (1,1,1)
\end{DoxyItemize}\hypertarget{md_docs_2zh_2md_23d__transforms_autotoc_md4}{}\doxysubsection{\texorpdfstring{2. 世界坐标 (World Space)}{2. 世界坐标 (World Space)}}\label{md_docs_2zh_2md_23d__transforms_autotoc_md4}

\begin{DoxyItemize}
\item {\bfseries{定义}}：整个3\+D场景的全局坐标系
\item {\bfseries{特点}}：所有物体都统一在这个坐标系中
\item {\bfseries{用途}}：确定物体在场景中的绝对位置和相对关系
\item {\bfseries{示例}}：房间中的桌子位于 (5,0,3)，椅子位于 (5,0,1)
\end{DoxyItemize}\hypertarget{md_docs_2zh_2md_23d__transforms_autotoc_md5}{}\doxysubsection{\texorpdfstring{3. 观察坐标 (View Space / Camera Space)}{3. 观察坐标 (View Space / Camera Space)}}\label{md_docs_2zh_2md_23d__transforms_autotoc_md5}

\begin{DoxyItemize}
\item {\bfseries{定义}}：以摄像机为原点的坐标系
\item {\bfseries{特点}}：摄像机位于原点，看向-\/\+Z方向，\+Y轴向上
\item {\bfseries{用途}}：简化后续的投影计算
\item {\bfseries{示例}}：摄像机前方2米的物体坐标为 (0,0,-\/2)
\end{DoxyItemize}\hypertarget{md_docs_2zh_2md_23d__transforms_autotoc_md6}{}\doxysubsection{\texorpdfstring{4. 裁剪坐标 (Clip Space)}{4. 裁剪坐标 (Clip Space)}}\label{md_docs_2zh_2md_23d__transforms_autotoc_md6}

\begin{DoxyItemize}
\item {\bfseries{定义}}：应用投影变换后的坐标系
\item {\bfseries{特点}}：包含齐次坐标的w分量，用于透视除法
\item {\bfseries{用途}}：进行视锥体裁剪，剔除不可见的几何体
\item {\bfseries{示例}}：坐标范围通常在 \mbox{[}-\/w, w\mbox{]} 之间

\begin{DoxyItemize}
\item {\bfseries{定义}}：经过透视除法后的标准化坐标
\item {\bfseries{特点}}：坐标范围固定在 \mbox{[}-\/1, 1\mbox{]} 之间（\+Open\+GL）或 \mbox{[}0, 1\mbox{]}（\+Direct\+X）
\item {\bfseries{用途}}：与具体屏幕分辨率无关的标准化表示
