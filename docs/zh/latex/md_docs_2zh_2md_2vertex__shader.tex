顶点着色器（\+Vertex Shader）允许你对顶点进行变换和处理。

想象一下：
\begin{DoxyItemize}
\item 你有一个图形，它由很多个顶点组成
\item 每个顶点都有自己的位置、颜色、纹理坐标等信息
\item 顶点着色器就像一个工人，负责处理每一个顶点
\item 它可以移动顶点位置、改变颜色、计算动画效果等
\item 为每个顶点计算需要传递给下一阶段的数据
\end{DoxyItemize}

{\bfseries{简单来说}}：顶点着色器决定了每个顶点的最终属性和位置，以及要传递给渲染管线下一阶段的信息。 \begin{quote}
{\bfseries{FCT库说明}}：在\+FCT中，你不需要从零开始写复杂的着色器代码，只需要定义数据结构和核心逻辑，\+FCT会帮你生成完整的着色器程序。 \end{quote}

FCT使用声明式的布局系统来定义着色器的输入输出：


\begin{DoxyItemize}
\item {\bfseries{Vertex\+Layout}} -\/ 定义顶点数据的结构和格式
\item {\bfseries{Pixel\+Layout}} -\/ 定义传递给像素着色器的数据
\item {\bfseries{Const\+Layout}} -\/ 定义常量缓冲区的结构
\item {\bfseries{Resource\+Layout}} -\/ 定义纹理和采样器等资源
\end{DoxyItemize}\hypertarget{md_docs_2zh_2md_2vertex__shader_autotoc_md80}{}\doxysubsection{\texorpdfstring{代码生成机制}{代码生成机制}}\label{md_docs_2zh_2md_2vertex__shader_autotoc_md80}

\begin{DoxyEnumerate}
\item {\bfseries{输入结构体}} ({\ttfamily Shader\+In}) -\/ 基于 {\ttfamily Vertex\+Layout}
\item {\bfseries{输出结构体}} ({\ttfamily Shader\+Out}) -\/ 基于 {\ttfamily Pixel\+Layout}
\item {\bfseries{常量缓冲区}} -\/ 基于 {\ttfamily Const\+Layout}
\item {\bfseries{资源绑定}} -\/ 基于 {\ttfamily Resource\+Layout}
